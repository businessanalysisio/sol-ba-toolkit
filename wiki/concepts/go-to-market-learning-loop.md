# Go To Market Learning Loop

Go To Market Learning Loop là cách Agentra học từ content performance, lead magnets, demos và audience response để cải thiện positioning và product roadmap.

## Mục tiêu

Không chỉ tạo nội dung để đăng. Mục tiêu là học:

- Persona nào phản hồi mạnh nhất?
- Pain point nào có sức kéo?
- Hook nào tạo trust?
- CTA nào dẫn tới demo hoặc practice starts?
- Product proof nào thuyết phục?

## Metrics

| Area | Metrics |
|---|---|
| Awareness | Reach, impressions, comments |
| Trust | Saves, shares, replies, qualitative feedback |
| Product interest | Clicks, downloads, demo requests |
| OpenEdu usage | Practice starts, topic suggestions, issue reports |
| EduFlow interest | Sample file downloads, workflow audit requests |

## Learning Outputs

- Updated persona notes
- New content angles
- Product backlog changes
- Lead magnet improvements
- Demo script improvements
- New BA use case briefs

## Strong Loops

### OpenEdu

Privacy content -> parent trust -> practice starts -> topic requests -> content and question bank improvements.

### EduFlow

Lesson planning content -> teacher pain validation -> sample workflow request -> matrix-to-lesson requirement refinement.

### Agentra

Human-approved AI positioning -> school leader engagement -> governance content -> approval workflow requirements.
