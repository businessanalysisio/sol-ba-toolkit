# Curriculum Traceability

Curriculum Traceability là khả năng truy vết từ chuẩn chương trình hoặc mục tiêu học tập đến tài liệu cuối cùng: slide, quiz, exam matrix, rubric hoặc question bank.

Trong [[agentra]], traceability là điểm khác biệt quan trọng so với generic AI. Nó giúp output không chỉ nhanh mà còn có thể kiểm tra.

## Ví dụ EduFlow

```text
GDPT 2018 objective
-> assessment matrix
-> slide section
-> STEM diagram
-> quiz question
-> answer key
-> exported file
```

## Ví dụ OpenEdu

```text
Grade/subject/topic
-> question
-> answer
-> issue report
-> review
-> corrected question
```
