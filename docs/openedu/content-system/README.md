# OpenEdu Content System

Core message:

> Luyen tap mo. Khong dang nhap. Khong thu thap du lieu ca nhan.

English:

> Open practice. No login. No personal data collection.

## Content Pillars

| Pillar | Core Angle | Example Topic |
|---|---|---|
| Privacy-first learning | Students can practice without giving personal data | Why OpenEdu does not require login |
| Open practice | Remove access barriers for quick study | Practice first, account never |
| Curriculum-aligned content | GDPT 2018 question bank | What makes a question bank trustworthy |
| Parent trust | Simple and safe practice support | How parents can let children practice without accounts |
| Teacher support | A supplementary resource, not a teacher replacement | How teachers can use OpenEdu for extra practice |
| Community quality | Report errors, improve questions, suggest topics | Open content gets better when the community participates |
| Agentra ecosystem | Agentra supports content workflows, OpenEdu supports student practice | From teacher materials to student practice |

## Folder Contents

- [Content Database Structure](content-database-structure.md)

- `agent-outputs/`: simulated outputs from the 9 content agents for OpenEdu.
- `blog/`: long-form OpenEdu articles.
- `social/`: reusable social post bank.
- `content-batch/`: launch and trust-building content batches.

## Recommended Publishing Order

1. Week 01: Launch OpenEdu with the no-login, privacy-first message.
2. Week 02: Build parent and teacher trust around local storage, curriculum alignment, and human guidance.
3. Week 03: Invite community participation through question reporting and topic suggestions.
