# Parent Guide: Safe Online Practice Without Student Accounts

Parents often want one simple thing: a safe place where their child can practice.

But many learning apps ask for personal information before a child can even begin.

That creates a fair question:

Does a child really need to create an account just to practice one topic?

OpenEdu's answer is no.

## What Parents Should Look For

When choosing an online practice tool, parents should check:

1. Does it require login?
2. Does it collect personal information?
3. Is the content aligned with the curriculum?
4. Can the child start quickly?
5. Are answers available?
6. Is there a way to report mistakes?
7. Does the platform clearly explain how data is handled?

## Why OpenEdu Stores Progress Locally

OpenEdu stores practice progress on the user's browser.

This means the progress stays on the device instead of being sent to a central student profile.

There is a trade-off: progress may not automatically sync across devices.

But the benefit is clear: OpenEdu does not need to collect personal data to support practice.

## What OpenEdu Provides

OpenEdu gives students access to:

- grade-based practice
- subject-based practice
- topic-based questions
- answers
- local progress
- a growing question repository aligned with GDPT 2018

It is built for self-study support, not for replacing teachers or parents.

## A Simple Home Practice Routine

Parents can use OpenEdu in a light, practical way:

1. Ask your child which topic feels difficult.
2. Open the matching grade and subject.
3. Let your child practice for 15-20 minutes.
4. Review incorrect answers together.
5. Ask the teacher if the child still feels stuck.

This keeps practice useful without turning the platform into pressure.

## Final Thought

Safe online practice should be simple.

Children should be able to learn without giving unnecessary personal information to every platform they use.

OpenEdu is built for that principle:

**Open practice. No login. No personal data collection.**
