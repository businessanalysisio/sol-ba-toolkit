# BA Skill To Agentra Map

This map connects Business Analysis skills to Agentra's product, content, and go-to-market work.

## Core Mapping

| BA Skill | Agentra Application | EduFlow Application | OpenEdu Application | Content Angle |
|---|---|---|---|---|
| Stakeholder Analysis | Identify teachers, academic managers, school leaders, operators, parents, students | Map teacher, subject lead, academic manager review roles | Map student, parent, teacher, contributor roles | Who should approve AI-generated academic documents? |
| Requirements Elicitation | Discover school workflow pain points | Interview teachers about lesson planning and assessment matrix workflows | Interview parents/teachers about privacy-first practice needs | What schools actually need from AI tools |
| Process Modeling | Model draft-review-approve-export workflows | Model matrix -> slides -> diagrams -> quiz -> export | Model choose grade -> subject -> topic -> practice -> local progress | Why schools need workflows, not prompts |
| Business Rules Analysis | Convert academic policies into workflow rules | Encode GDPT 2018, Circular 22, Official Dispatch 5512 constraints | Encode no-login, no personal data, local storage rules | Human approval is a business rule |
| Requirements Traceability | Connect education need to requirement to artifact | Trace curriculum objective -> matrix -> slide -> quiz -> exported file | Trace GDPT topic -> question -> answer -> quality issue -> fix | From curriculum standard to usable output |
| Acceptance Criteria | Define when generated content is usable | Define lesson pack approval criteria | Define question quality and privacy criteria | How to know an AI-generated lesson plan is ready |
| Risk Analysis | Identify AI quality, privacy, compliance, adoption risks | Control hallucination, wrong diagrams, bad quiz answers | Control question errors, privacy misunderstandings | The risks of education AI without review |
| Data Quality | Maintain trustworthy content and metadata | Validate diagrams, formulas, standards, quiz keys | Validate question bank accuracy and issue reports | A question bank is only as good as its QA process |
| Prioritization | Decide MVP features and content focus | Prioritize matrix-to-slide and STEM diagram workflows | Prioritize no-login practice and error reporting | What to build first in education AI |
| Value Proposition Canvas | Clarify customer pains, gains, jobs | Position EduFlow for teacher workload and academic consistency | Position OpenEdu for privacy-first student practice | Clear AI value without hype |
| SWOT Analysis | Evaluate Agentra market position | Compare with generic lesson plan generators | Compare with account-based practice apps | Where Agentra can own trust and workflow |
| Customer Journey Mapping | Understand end-to-end adoption path | Teacher discovers -> creates -> reviews -> exports -> reuses | Student opens -> practices -> parent trusts -> teacher recommends | The journey from interest to habit |
| Root Cause Analysis | Identify why school documents are inconsistent | Manual template copying and disconnected assessment design | Account barriers and content trust gaps | Fix the workflow, not just the symptom |
| Metrics And KPIs | Define success measures | Time saved, approval rate, export rate | Practice starts, content reports, topic coverage | Measuring useful education AI |
| Change Management | Help schools adopt AI safely | Move teachers from manual prep to reviewed AI workflow | Help communities trust no-login practice | AI adoption is a workflow change |

## Agentra POV

Generic AI tools focus on output generation. Agentra should focus on managed education workflows:

```text
Education need
-> BA requirement
-> AI-assisted workflow
-> human approval point
-> export-ready artifact
-> performance feedback
```
