# Presentation skills

## Overview

Presentation skills describes a practitioner capability used to support project and product outcomes. It helps the BA align stakeholders, requirements, delivery constraints, and value measures.

## Context & Usage

Use this capability across initiation, planning, execution, and evaluation when presentation skills affects scope, stakeholder alignment, quality, or benefit realization.
