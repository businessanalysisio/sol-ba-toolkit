# Communication skills (business writing + verbal)

## Overview

Communication skills (business writing + verbal) describes a practitioner capability used to support project and product outcomes. It helps the BA align stakeholders, requirements, delivery constraints, and value measures.

## Context & Usage

Use this capability across initiation, planning, execution, and evaluation when communication skills affects scope, stakeholder alignment, quality, or benefit realization.

* Stakeholder Map, Power/Interest Grid, Communication Plan, Needs Assessment, Traceability, Solution Evaluation
