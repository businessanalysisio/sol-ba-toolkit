# Techniques and documentation (translating agreements into clear, detailed written artifacts)

## Overview

Techniques and documentation (translating agreements into clear, detailed written artifacts) is a business analysis practice for handling business analysis and decision making. It helps the BA move from ambiguous stakeholder input to structured analysis, documented decisions, and actionable outputs.

## Context & Usage

Use this when techniques and documentation is creating uncertainty, disagreement, or missing detail. The BA should clarify purpose, collect evidence, involve the right stakeholders, and convert the result into a documented artifact or decision.
