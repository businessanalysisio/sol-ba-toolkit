# Building stakeholder consensus on project direction and scope

## Overview

Building stakeholder consensus on project direction and scope is a business analysis practice for handling stakeholder collaboration and elicitation. It helps the BA move from ambiguous stakeholder input to structured analysis, documented decisions, and actionable outputs.

## Context & Usage

Use this when building stakeholder consensus on project direction and scope is creating uncertainty, disagreement, or missing detail. The BA should clarify purpose, collect evidence, involve the right stakeholders, and convert the result into a documented artifact or decision.
