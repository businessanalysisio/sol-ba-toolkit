# Adapting requirements for COTS packages

## Overview

Adapting requirements for COTS packages is a business analysis practice for handling requirements and product definition. It helps the BA move from ambiguous stakeholder input to structured analysis, documented decisions, and actionable outputs.

## Context & Usage

Use this when adapting requirements for COTS packages is creating uncertainty, disagreement, or missing detail. The BA should clarify purpose, collect evidence, involve the right stakeholders, and convert the result into a documented artifact or decision.
