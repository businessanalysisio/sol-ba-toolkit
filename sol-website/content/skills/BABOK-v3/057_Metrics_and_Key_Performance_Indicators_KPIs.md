# Metrics and Key Performance Indicators (KPIs)

## Overview

Defining measurable performance indicators tied to business objectives. KPIs and metrics translate strategy into quantifiable targets that can be tracked over time.

## Context & Usage

Applied in Strategy Analysis (setting future state success metrics), RADD (defining acceptance criteria), and Solution Evaluation (measuring performance). Good KPIs are SMART: Specific, Measurable, Achievable, Relevant, Time-bounded. Leading indicators predict future performance; lagging indicators report past performance.
