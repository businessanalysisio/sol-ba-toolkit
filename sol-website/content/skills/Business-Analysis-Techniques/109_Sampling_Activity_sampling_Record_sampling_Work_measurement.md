# Sampling / Activity sampling / Record sampling / Work measurement

## Overview

Sampling / Activity sampling / Record sampling / Work measurement is a business analysis technique for process analysis and operational improvement. It provides a structured way to examine the situation, compare options, and produce an artifact that stakeholders can review.

## Context & Usage

Use this technique during process analysis and operational improvement work when a team needs a shared view of facts, options, impacts, or decisions. Define scope first, facilitate input from relevant stakeholders, and record outcomes with owners and follow-up actions.
