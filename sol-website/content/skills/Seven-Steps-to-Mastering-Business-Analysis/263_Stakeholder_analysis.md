# Stakeholder analysis

## Overview

Stakeholder analysis is a practical BA capability for progressing from unclear business need to agreed requirements and delivery-ready understanding.

## Context & Usage

Apply this when entering a new initiative, preparing elicitation, analyzing findings, or driving agreement. The expected output should be specific enough to support stakeholder review and next-step planning.

## Related Techniques / Tools

* Stakeholder Map, Power/Interest Grid, Communication Plan, Elicitation Planning, Requirements Analysis
