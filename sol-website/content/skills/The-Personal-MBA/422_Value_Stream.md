# Value Stream

## Overview

Value Stream is a business mental model for understanding process analysis and operational improvement. It gives operators a compact lens for diagnosing a situation, naming the forces at work, and choosing a practical next action without overcomplicating the analysis.

## Context & Usage

Use this model when a business conversation needs clearer thinking about process analysis and operational improvement. Start by naming the current situation, identify which assumptions or constraints are driving outcomes, then use the model to choose one experiment, policy, metric, or decision to test next.
