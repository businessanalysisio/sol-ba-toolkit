# Requirements manager

## Overview

Requirements manager describes a practitioner capability used to support project and product outcomes. It helps the BA align stakeholders, requirements, delivery constraints, and value measures.

## Context & Usage

Use this capability across initiation, planning, execution, and evaluation when requirements manager affects scope, stakeholder alignment, quality, or benefit realization.

* Backlog Management, Requirements Traceability, Acceptance Criteria, Needs Assessment, Traceability, Solution Evaluation
