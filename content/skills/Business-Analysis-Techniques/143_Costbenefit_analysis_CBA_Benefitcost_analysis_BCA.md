# Cost–benefit analysis (CBA) / Benefit–cost analysis (BCA)

## Overview

Cost–benefit analysis (CBA) / Benefit–cost analysis (BCA) is a business analysis technique for commercial and financial analysis. It provides a structured way to examine the situation, compare options, and produce an artifact that stakeholders can review.

## Context & Usage

Use this technique during commercial and financial analysis work when a team needs a shared view of facts, options, impacts, or decisions. Define scope first, facilitate input from relevant stakeholders, and record outcomes with owners and follow-up actions.
