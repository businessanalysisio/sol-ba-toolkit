# Skill Library

This directory contains the Sol business-analysis skill library: 651 markdown skills generated from the master skill map and enriched for agent use.

## Lookup Files

* `index.md` - human-readable table of all skills.
* `manifest.json` - source manifest with paths and tags.
* `catalog.json` - searchable catalog with summaries, paths, and tags.

## Local Search

Run `python3 scripts/search_skills.py requirements traceability` from the project root to search by keyword.
Use `--tag requirements`, `--source "The Personal MBA"`, or `--limit 20` to narrow results.

## Validation

Run `python3 scripts/validate_skills.py` after regenerating or enriching skills.
