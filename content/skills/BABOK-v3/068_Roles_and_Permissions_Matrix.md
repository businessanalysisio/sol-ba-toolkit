# Roles and Permissions Matrix

## Overview

Mapping system functions to user roles and the permissions each role has. The Roles and Permissions Matrix (also called RACI for security) defines who can access, create, modify, or delete what.

## Context & Usage

Applied during RADD (specifying security and access requirements). Structure: rows are system functions/objects; columns are roles; cells indicate permission level (Create, Read, Update, Delete, Admin) or access type (View, Edit, Approve). Essential for compliance, audit, and secure system design.
