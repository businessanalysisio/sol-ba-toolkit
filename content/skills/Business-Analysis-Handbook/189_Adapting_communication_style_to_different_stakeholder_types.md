# Adapting communication style to different stakeholder types

## Overview

Adapting communication style to different stakeholder types is a business analysis practice for handling stakeholder collaboration and elicitation. It helps the BA move from ambiguous stakeholder input to structured analysis, documented decisions, and actionable outputs.

## Context & Usage

Use this when adapting communication style to different stakeholder types is creating uncertainty, disagreement, or missing detail. The BA should clarify purpose, collect evidence, involve the right stakeholders, and convert the result into a documented artifact or decision.
