# Stakeholder identification and analysis for analytics initiatives

## Overview

Stakeholder identification and analysis for analytics initiatives is an analytics skill for converting business questions into evidence-led decisions. It clarifies what needs to be known, what data or analysis is appropriate, and how findings should influence business action.

## Context & Usage

Apply this before analysis begins and again when interpreting results. Define the business decision, expected evidence, data limitations, analysis method, and stakeholder action so the analytics work does not become detached from the original need.

* Stakeholder Map, Power/Interest Grid, Communication Plan, Research Questions, Data Quality, Metrics and KPIs
