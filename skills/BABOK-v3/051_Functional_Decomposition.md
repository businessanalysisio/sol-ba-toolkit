# Functional Decomposition

## Overview

Breaking complex systems or processes into smaller, more manageable components. Functional decomposition creates a hierarchical view of what a system does, without describing how it does it.

## Context & Usage

Applied during RADD (specifying requirements architecture), during Scope Modelling, and when building a Work Breakdown Structure (WBS). Decompose from the highest-level function down to atomic activities. Each level refines the level above. Stop decomposing when the function is clearly understood and can be specified or estimated.
