# Brainstorming

## Overview

Divergent idea generation in a group setting. Key rules: defer judgment, go for quantity, encourage wild ideas, and build on others' ideas. Brainstorming is the starting point for creative problem solving.

## Context & Usage

Applied when generating solution options, identifying risks, exploring root causes, or defining requirements scope. Best with 5-10 participants from diverse perspectives. Separate ideation (divergent) from evaluation (convergent) — never critique during brainstorming. Record all ideas visibly; cluster and prioritize afterward.
