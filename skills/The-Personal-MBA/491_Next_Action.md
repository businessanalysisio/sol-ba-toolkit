# Next Action

## Overview

A Next Action is the single, concrete, physical step that moves a project forward right now — and Kaufman (borrowing from David Allen's Getting Things Done) argues it is the only thing you can ever actually do. Projects are abstractions; "launch the website" or "improve onboarding" cannot be performed, because they are outcomes, not actions. What you can do is "email the designer the logo files" or "write the first three sign-up screen headlines." The discipline is to translate every stalled commitment into its very next physical action, small enough to start without further thinking. Vague items sit untouched precisely because the mind cannot execute a category; naming the concrete next move removes the friction between intention and doing.

## Context & Usage

Use this whenever a task list has gone stale or a project feels stuck. Procrastination is often a symptom of an item defined at too high an altitude — "do taxes" paralyzes, "find last year's return in the file drawer" is trivially startable. Go through anything that is not moving and ask, "What is the very next physical action?" then reword the item to that. For a team, requiring that every open item carry an explicit next action (and an owner) exposes the ones that are really just wishes. It pairs naturally with Externalization (492): get the projects out of your head, then reduce each to its next action so the list becomes executable rather than merely aspirational.
