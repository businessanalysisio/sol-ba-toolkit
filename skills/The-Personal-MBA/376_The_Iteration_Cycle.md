# The Iteration Cycle

## Overview

The Iteration Cycle is Kaufman's repeating loop for improving anything through cheap, rapid rounds of trial and correction. He breaks each pass into six steps: **Watch** what is actually happening, **Ideate** possible improvements, **Guess** which change will help most, decide **Which** one to try, **Act** on it, then **Measure** the result — and feed that measurement into the next Watch. The power is in repetition: no single pass has to be right, because each cycle uses real-world results to steer the next. This reframes progress from a matter of upfront brilliance to a matter of running many honest loops. Great offers are almost never designed correctly the first time; they are iterated into shape.

## Context & Usage

Use the iteration cycle whenever you are developing or refining an offer under uncertainty — which is nearly always. Rather than debating the perfect version in a meeting, ship a rough prototype, watch how people use it, change one thing, and measure again. A landing page that converts poorly should not be redesigned by argument; run cycles, testing one headline or layout change at a time, and let the numbers choose. The discipline is to keep each loop small and fast so that many can be run — which is exactly what iteration velocity (377) optimizes.
