# Value Stream

## Overview

A Value Stream is the complete, end-to-end sequence of steps a business runs to create and deliver value — from the first raw input to the finished value in the customer's hands. Kaufman frames it as the union of two processes usually discussed separately: value creation (designing and building the offer) and value delivery (getting it to the customer and supporting them). Mapping the whole stream as one connected flow reveals where value is actually added versus where it merely sits, waits, or gets reworked. A coffee shop's value stream runs from sourcing beans through roasting, brewing, serving, and cleanup; a software firm's runs from writing code through building, deploying, onboarding, and support. Seeing the stream as a whole is the prerequisite for improving it, because the biggest constraints are usually at the handoffs between stages, not inside any single step.

## Context & Usage

Map the value stream whenever you want to improve delivery speed, cost, or quality but don't yet know where the real bottleneck is. Example: an e-commerce operator diagrams every step from order placed to package delivered and discovers the delay isn't in shipping but in a manual fraud-check step that holds orders for a day — a stage that adds no customer value. Once mapped, attack the constraint (the throughput-limiting step) rather than optimizing stages that are already fast. The map also exposes duplicated effort and steps a customer would never pay for.
