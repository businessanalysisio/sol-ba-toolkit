# Contrast

## Overview

Perception is relative, not absolute: the mind judges everything against whatever is nearby. A $500 jacket feels expensive alone and cheap next to a $2,000 one; lukewarm water feels hot to a hand that was in ice. There is no direct sense for "how much is this worth" — only "how does this compare to the reference in front of me," which means whoever controls the comparison controls the perception.

## Context & Usage

Set the reference point on purpose. In pricing: present three tiers so the middle option looks reasonable, open negotiations with an anchor, and show the crossed-out original price beside the offer. In proposals: include the do-nothing cost so your fee is compared against the problem, not against zero. Defensively, notice when a counterparty is staging a contrast on you — the "concession" that only looks generous next to the outrageous first demand. Change the comparison and the same offer reads completely differently.
