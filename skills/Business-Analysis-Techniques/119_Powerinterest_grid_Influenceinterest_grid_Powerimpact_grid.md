# Power/interest grid / Influence/interest grid / Power/impact grid

## Overview

A matrix that positions each stakeholder by two attributes — their power (or influence) over the change and their interest in (or impact from) it — so that engagement effort can be allocated deliberately. The widely taught 2x2 form, tracing back to Aubrey Mendelow's 1991 stakeholder mapping, yields four strategies: manage closely (high power, high interest — the key players), keep satisfied (high power, low interest), keep informed (low power, high interest) and monitor with minimal effort. The Cadle/Paul treatment refines this into a 3x3 grid (power and interest each rated low/some/high), producing more graduated strategies ranging from "ignore" through "watch", "keep informed", "keep satisfied" and "keep onside" up to "constant, active management".

## Context & Usage

Completed after stakeholder identification and before planning communications: plot every stakeholder, then let the grid position drive frequency, channel and depth of engagement. Two practice points matter. First, the assessment is sensitive — grids labelling a named director "low interest" should not circulate freely, so treat the artefact as a working document. Second, positions move: a keep-informed group can acquire power when go-live approaches, so re-plot at each phase boundary.
