# RACI / RASCI / ARCI charts

## Overview

A linear responsibility matrix with activities or deliverables as rows and roles as columns, where each cell carries at most one code: Responsible — does the work; Accountable — answerable for the outcome and the one who signs it off; Consulted — provides input before the work is done (two-way communication); Informed — told of the result afterwards (one-way). The governing rule is exactly one A per row — shared accountability is no accountability — while several roles may be R. The RASCI variant adds Supportive (helps the Responsible role do the work); ARCI is the same scheme with Accountable listed first. Reading the completed grid down a column exposes overloaded or under-used roles; reading across a row exposes activities with too many hands in them or nobody consulted at all.

## Context & Usage

Drawn up when responsibility for project activities, process steps or deliverables is ambiguous or contested — commonly during stakeholder management planning, process redesign handover, or governance definition. The chart is negotiated with the named role-holders rather than imposed, because the argument it provokes ("why am I only Consulted on this?") is precisely the clarification being sought. Watch for rows where the same person is both R and A on everything (a bottleneck) and columns full of C and I (a stakeholder being placated rather than engaged).
