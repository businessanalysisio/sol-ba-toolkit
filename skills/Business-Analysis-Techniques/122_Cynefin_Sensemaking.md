# Cynefin / Sensemaking

## Overview

Dave Snowden's sense-making framework (developed at IBM from 1999; "Cynefin" is Welsh for habitat) that classifies situations into five domains, each demanding a different response pattern. Clear/obvious: cause and effect are evident — sense, categorise, respond with best practice. Complicated: cause and effect are discoverable by expertise — sense, analyse, respond with good practice. Complex: cause and effect are only visible in retrospect — probe with safe-to-fail experiments, sense, respond, letting practice emerge. Chaotic: no discernible causality — act first to stabilise, then sense and respond. The fifth domain, confusion (disorder), is not knowing which domain you are in, where people default to their habitual style.

## Context & Usage

For a BA, Cynefin is a meta-technique: it determines which analysis approach fits the problem before any technique is chosen. A complicated problem rewards detailed modelling, expert interviews and up-front specification; a complex one (typically anything involving changing human behaviour at scale) rewards prototypes, pilots and iterative delivery, where demanding a full requirements specification up front is itself the error. It is also a useful workshop device for defusing method arguments — much disagreement about "agile versus plan-driven" dissolves once participants agree which domain the problem occupies.
