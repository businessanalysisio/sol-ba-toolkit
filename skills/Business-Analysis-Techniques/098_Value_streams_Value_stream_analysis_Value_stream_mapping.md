# Value streams / Value stream analysis / Value stream mapping

## Overview

A lean technique (popularised through the Toyota Production System and Womack & Jones's lean movement) that traces the end-to-end flow of activities delivering value to a customer, from initial trigger to value received. A value stream map records each step together with timing data — distinguishing process time (work actually being done) from lead time (elapsed time including waiting) — and classifies steps as value-adding or non-value-adding from the customer's viewpoint. The ratio of value-adding time to total lead time is often startlingly low, which is precisely the point: the map makes waste (delays, handoffs, rework, queues) visible and quantifiable.

## Context & Usage

Drawn when an organisation wants to improve speed or cost across a whole customer journey rather than inside one department. The standard sequence is: map the current state with real observed timings, identify waste and bottlenecks, design a future-state map, then plan the transition. Value streams sit above individual processes — one value stream ("order to cash") may span many swimlane process models — so BAs use them to frame which processes deserve detailed modelling and redesign effort.
