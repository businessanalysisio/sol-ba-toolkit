# Repertory grid

## Overview

An elicitation technique derived from George Kelly's personal construct theory (1955) that surfaces the tacit distinctions an expert uses but cannot easily articulate. The interviewee is given a set of elements (e.g. suppliers, systems, job roles) and repeatedly shown them in triads with the question: "in what way are two of these alike and different from the third?". Each answer yields a bipolar construct (such as "responsive — slow to react"), and every element is then rated against every construct on a numeric scale, producing a grid that can be analysed for clusters and patterns. The output is a map of how that person actually categorises their world.

## Context & Usage

Valuable in knowledge-intensive investigations where standard interviews return vague generalities — for instance capturing the evaluation criteria a seasoned underwriter, buyer or support engineer applies unconsciously. BAs use the elicited constructs to define classification rules, assessment criteria or system attributes, and to compare mental models across stakeholders (two managers rating the same elements very differently is itself a finding). It is time-consuming per participant, so reserve it for genuinely tacit expertise.
