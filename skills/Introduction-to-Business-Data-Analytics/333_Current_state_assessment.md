# Current-state assessment

## Overview

Establishing a factual, quantified baseline of how things stand today, so the size of the problem and the value of any change can be measured rather than asserted. It draws on existing metrics, process observation, system data, and stakeholder input to describe current performance, its drivers, and its variability. Without a solid current-state picture there is no reference line: you cannot claim a future-state target is ambitious or an improvement is real if you never pinned down where you started.

## Context & Usage

An activity in the Identify domain, following problem definition and feeding the future-state and question-formulation steps (identify → source → analyze → interpret & report → use). Concrete example: after defining premium churn as the problem, the current-state assessment documents that premium quarterly churn has averaged 18% over the last six quarters, ranges 15-21% by region, and that the segment generates 40% of revenue — numbers that anchor the target and reveal which regions to probe.
