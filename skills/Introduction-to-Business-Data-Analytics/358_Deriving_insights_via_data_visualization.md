# Deriving insights via data visualization

## Overview

Using visual encodings — bar, line, scatter, heatmap, box plot, and the like — to both discover patterns in data and communicate them clearly. Visualization serves two ends: as an analytical tool it exposes trends, comparisons, distributions, correlations, and outliers that tables of numbers hide; as a communication tool it makes a finding self-evident to an audience. Doing it well means matching the chart type to the question (comparison, composition, distribution, relationship, or trend over time), respecting perceptual best practice (honest axes, minimal clutter, accessible color), and letting the visual carry one clear message rather than everything at once.

## Context & Usage

Used both in the Analyze domain (as part of exploratory analysis) and in Interpret & Report (to convey results) (identify → source → analyze → interpret & report → use). Concrete example: for the churn work, a line chart of churn rate over time first reveals the step-change traced to a data-load gap during exploration; later, a bar chart contrasting churn across delivery-delay buckets becomes the single visual that makes the "delays drive premium churn" finding obvious to the sponsor without any statistical explanation.
